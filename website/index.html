Quick Installation Guide

Deploy KALKI in your Chrome browser in 5 simple steps.

Step 01

Download & Extract

Click "Download Free" to download kalki-extension.zip. Right-click and extract the ZIP file to a folder on your computer.

Step 02

Open Extensions Page

Open Google Chrome and type chrome://extensions/ in the URL bar, or navigate to Chrome Menu → Extensions → Manage Extensions.

Step 03

Enable Developer Mode

In the top-right corner of the Extensions page, toggle the Developer mode switch to ON.

Step 04

Load Unpacked

Click the "Load unpacked" button in the top-left corner, and select the extracted folder (ensure it contains manifest.json).

Step 05

Pin & Start Protecting!

KALKI is now active. Click the puzzle icon in your Chrome bar, pin KALKI, and connect your Gmail account from the dashboard to start scanning.
